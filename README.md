
 ## Project Overview
 
A mobile application for ordering food online.
Users can browse restaurants and food items.
Users can add food to cart and place orders.
Provides convenient and fast food delivery.

 ## Objectives 
Make food ordering simple and convenient.
Help users find restaurants and dishes easily.
Provide a smooth and user-friendly experience.
Enable easy and secure online payments.
Allow users to track their orders.

## Features
User registration and login
Restaurant search
Food categories
Food details and prices
Add to cart
Online payment
Order tracking
Order history
Ratings and reviews
Notifications

## Design Highlights
Simple and clean interface
Attractive food images
Easy navigation
Clear buttons and icons
Consistent colors and typography
Mobile-friendly layout
Simple checkout process
